## Steady figures far from the origin

- **Fix:** characters no longer shimmer when they stand far from the world's origin. Skinning ran on world-space bone matrices, and the GPU's 32-bit floats only resolve millimetres tens of kilometres out (3.9 mm at 32 km), so every vertex landed a little off, differently each frame; garments, a few millimetres over the skin, showed it most. Skeletons are now `RootSkeleton`s: the character's root transform is taken out on the CPU in double precision, so the GPU only sees offsets within the figure. Meshes are bound with `bindRoot` (detached bind mode); CPU skinning (`getVertexPosition`, raycasts) still returns mesh-local positions.
