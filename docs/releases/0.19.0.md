## Library animals

- **100 ready-made animals** (WildMesh3D: 64 realistic, 36 stylized; 3,744 clips) can now be used through Actors. The models are licensed for Arnd's projects only and live in the private repository ArndRosemeier/PrivateAssets; Actors has the loader and a catalogue of names and facts, never the files. How a game adds them: docs/using-actors.md, "Library animals".
- **`loadLibraryAnimal(id, { baseUrl, rootMotion })`** (`@actors/three`): loads an animal once and clones it for every further call. `play`, `update`, `clipFor("walk")`, `speedOf(clip)`, `lods`/`setLod`/`updateLod` (farther levels update the animation less often and drop shadows), `height`, `dispose`.
- **Root motion:** `"in-place"` (default) reports each frame's travel, `"move"` moves the animal's object along it, `"keep"` plays clips as authored. Clips made to play on the spot get a ground speed estimated from the planted foot, so every walk, trot and run has one.
- **Catalogue** (`@actors/animal/library`): `LIBRARY_ANIMALS` (id, name, set, group, rig family, size, triangles, clips with lengths and channel counts), `findLibraryAnimals`, `libraryAnimal`, `libraryClips`. `pickLibraryClip` (`@actors/core`) picks the plain loop for a motion from the pack's varied clip names.
- **Viewer:** `library.html` lists every animal and its clips (text only); with `?base=<local URL>` it previews the private models in 3D.
