## What's new: crowds, poses and locomotion

Work from the game Scale, which now draws every person as an Actors character.

**Big crowds of characters**
- **Only what a character wears is fitted and drawn.** Garment and hair meshes are made the first time they're shown, and shapes fit only the worn garments (`ThreeActor.neededMeshes`), however much of the wardrobe the shared pack has loaded.
- **Visibility changes are batched.** `setVisible` and `setConcealed` take effect on the next update, shape or level change, so a whole outfit costs one pass. `flushVisibility()` applies them right away.
- **Worker pools.** Characters can share with several leads that each have their own worker, so shapes are fitted in parallel.
- **`actor.crowdMesh()`** returns the "Crowd" level's merged mesh and the vertex range each garment fills, e.g. for baking vertex-animation textures.

**Fixes**
- On-demand garments that finish loading during a change now show up (sneakers used to stay missing until the next change).
- Garments no longer go missing on shared workers, and seams no longer show pinholes at a distance: cut-outs test the colour texture's full-resolution alpha.
- **Skin:** the soft wrap-around light only feeds the diffuse lobe. Before, it also fed the highlight, which lit up red along edges facing away from the sun (wrists, fingertips, beards).
- `npx actors-packs` unpacks from Git Bash on Windows too (relative tar paths).

**Poses and locomotion** (`@actors/core`, renderer-free)
- **Pose buffers:** `createPose`, `bindPose`, `copyPose`, `blendPoses` (normalized lerp on the short arc, optional per-bone mask) and `poseWorld` (forward kinematics).
- **`PoseMixer`** blends any number of poses as rotations, never as angles, with per-bone masks.
- **`Retargeter.sampleInto(time, pose)`** samples without allocating, for many characters every frame. A new option, `inPlace: "drift"`, removes only the steady travel over a loop and keeps the hips' sway.
- **`Locomotion`** blends walk, jog and sprint (or any looping gaits) by ground speed, with all clips in step. `measureGait` measures each clip's stride, speed and left-foot strike, including in-place loops (from how fast the planted foot moves back). Advance one phase by distance ÷ `stride(weights)` and feet never slide.
- `ThreeActor.fittedSkeleton` and `ThreeActor.setPose(pose)` let a game sample and blend clips itself.

**Editor**
- The genital sliders and the crotch bulge slider are hidden while anatomical detail is off.

## How to use it

```ts
import { Locomotion, createPose } from "@actors/core";

const loco = new Locomotion(actor.fittedSkeleton!, [
  { clip: walk, from: 0, to: 1.9 },    // full weight up to 1.9 m/s
  { clip: jog, from: 3.6, to: 5.6 },
  { clip: sprint, from: 7.6, to: 1e9 },
]);
const pose = createPose(actor.fittedSkeleton!.names.length);
// every frame:
const w = loco.weights(speed);
phase = (phase + (speed * dt) / loco.stride(w)) % 1;
character.actor.play(null);
actor.setPose(loco.sample(phase, w, pose));
```
