## Smarter body sliders

The raw MakeHuman sliders (about 250 of them under Details) are precise but hard to use: making someone "broad-shouldered" means finding and balancing five of them. This release adds a layer on top. The raw sliders stay exactly as they were, and the new controls only add to them.

- **Body type** (under Body): twelve starting points (average, slim, athletic, muscular, curvy, hourglass, pear, inverted triangle, stocky, heavy, tall and lanky, petite). Each sets muscle, weight, height and proportions plus the shape sliders below. Gender, age and ethnicity stay as they are.
- **Shape** (a new editor section): 24 named sliders, each moving several raw modifiers together. Body: body fat, fitness, shoulders, chest, waist, belly, hips, bottom, leg length, thighs, arms, neck, head. Face (in detailed mode): face width, fullness, jaw, cheekbones, brow, eyes, nose, nose width, lips, mouth width, chin. All run from -1 to 1 with 0 meaning "no change".
- Saved as `CharacterConfig.shape` (slider id to value; empty by default, so old saves look the same). Randomize now varies some of them a little.
- For games: `SHAPE_SLIDERS`, `BODY_TYPES` and `shapeModifiers()` come from `@actors/human`. The editor section has the id `"shape"`, so `sections` can leave it out, and single sliders hide by key (`shape.waist`).

No shape slider touches breasts or genitals, and body types never change age. Costs nothing at run time: the values fold into the same modifier weights the raw sliders use. `apps/viewer/scripts/shapes.mjs` renders body types front and side.
