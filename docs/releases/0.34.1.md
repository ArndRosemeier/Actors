## Only humans: no horns, tails or scales either

- **Race features follow `allow.races`.** Horns, tails, tusks, glowing eyes, slit and goat pupils and skin patterns like scales or bark belong to some races. When a game allows only some races (`allow: { races: ["human"] }`), the editor now offers only the features those races have (humans: freckles, no horns, tails, tusks or glowing eyes), and `set` takes the others off a loaded look, so an old drakeborn turns into a plain human rather than a human with horns. With every race on offer nothing changes. `raceFeatures(races, all)` tells a host what is on offer.
