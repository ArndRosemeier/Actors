## Commonwear 3026: a future wardrobe

An initial collection for an expressive, utopian, spacefaring post-scarcity society: seven morphable textile pieces and a procedural orbital halo, arranged into three complete outfits.

- **Common ground** (`future-daily`): asymmetric wrap, transit trousers, conversation cuffs, keepsake belt and habitat gaiters.
- **Aurora commons** (`future-orbit`): a layered screen mantle and luminous orbital halo.
- **Living constellation** (`future-festival`): a living canvas top, screen cuffs and intersecting light rings.
- **Animated screen fabrics** use slow aurora ribbons over a dark textile backing. They work with the WebGL and node-material adapters, follow garment recolouring, update at most 12 times per second per visible material, and release their textures when disposed.
- **Editor and API:** the new pieces appear in Future clothing, screens and accessories groups. Presets include design descriptions, and the viewer accepts `?outfit=future-orbit` for a direct preview. `FUTURE_OUTFITS` is exported by `@actors/generator`.

## Use the collection

Install the updated packages and matching asset pack, then call:

```ts
await character.wear("future-orbit");
```

Older asset packs do not contain the new garment IDs. Run `npx actors-packs` after updating, or regenerate with `npm run import:human` when working in the repository.

The screen surfaces are emissive, not scene lights. glTF exports preserve a texture snapshot and skeletal animation; the procedural screen motion is not exported. Crowd LOD uses flat colours. Existing cloth clipping and simulation limitations still apply, and the halo can intersect large hair or horns.

See [the collection's design notes](https://github.com/ArndRosemeier/Actors/blob/v0.7.0/docs/future-wardrobe.md) for its fictional setting, individual pieces and implementation limits.

## Validation

Type checking, 130 unit tests, production build and the standard viewer smoke test passed locally. Focused browser checks passed for all three outfits on two adult body shapes in WebGL and the node-material renderer's WebGL backend, including changing screen pixels, recolouring, finite geometry and emissive glTF export. Screenshots were visually inspected.
