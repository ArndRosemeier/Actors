## Commonwear 3026: more silhouettes

Eight new pieces expand the future wardrobe to sixteen items and eight coordinated looks.

- **Five new pants options:** Comet flares, Cocoon pants, Courtyard culottes, Lightstream screen leggings and asymmetric Drift shorts. The original Transit trousers remain available.
- **More layers:** the Arc vest, Solstice bolero and animated Memory ribbon sash.
- **Five new outfits:** Comet trails, Garden commons, Open courtyard, Lightstream and Drift afternoon.
- **Easier mixing:** a dedicated **3026 pants** selector in both editor modes, plus separate Future tops and pants groups in Detailed mode.
- **Distinct geometry:** four pants designs use sculpted proxy offsets, preserving body morphs and skeletal animation while adding volume. Full-length wide pants replace gaiters when selected.

## Fixed: screen fabrics in installed WebGPU packages

The release builder previously bundled the main and WebGPU entry points independently. Each bundle had its own screen-material registry, so screens created through `@actors/three/webgpu` were invisible to the main entry's animation and emission-colour updates. Source-based viewer checks did not expose the issue.

Release entry points now share internal modules. A regression check installs the actual tarballs into a fresh consumer app and verifies animation, tint, colour reset and independent materials across the two public imports. The check fails with the old independent bundles and passes with shared chunks. Release checks also use the npm CLI through Node when launched with npm, supporting Windows.

## Update

Install the 0.8.0 packages and refresh the matching asset pack with `npx actors-packs`. Older packs do not contain the new garments.

```ts
await character.wear("future-comet");
// Or: future-garden, future-courtyard, future-lightstream, future-drift.
```

Screen surfaces emit colour without lighting the surrounding scene. Crowd LOD retains flat colours; glTF exports a screen-texture snapshot rather than its procedural animation. Garment hems use runtime clipping, and the shaped pants use skeletal deformation rather than cloth simulation.

## Validation

Type checking, 131 unit tests, the production build, installed-tarball consumer checks and the standard viewer smoke test passed. Focused browser checks covered all eight outfits on two adult body shapes, changing screen pixels, tint/reset, emissive glTF export, the pants selector and detail-level switching. Front and back previews were inspected. The packaged node-material renderer was exercised through its WebGL fallback; native WebGPU rendering was not verified on this machine.
