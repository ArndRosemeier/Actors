## Dressing without a stall

With a worker, `Character.set` no longer builds a new person's generated parts (a beard, horns, a tail) or face morphs (the expression and the blink) on the main thread. The worker builds them along with the shape and hands them over with it. A beard alone used to take tens of milliseconds on the main thread. What is left on the main thread (applying the shape, the parts, the face morphs) now runs as separate tasks, so the browser can draw frames in between.

- `Human.extras`: the parts and face deltas the next shapes will be asked for. When it is set, `evaluate` (with a worker) builds them in the worker, and `parts` and `faceDelta` for that shape return them at no cost. `Character` sets it itself.
- Worker shape tasks (`ShapeTask`, see `serveRuntime`) may be async. The human worker serves `EXTRAS_TASK`.
- Without a worker, nothing changes.

The asset packs are unchanged. This release only needs a package update.
