## Face rig: every face unit as its own GPU morph

An optional face rig (`faceRig: true` in the character config, "Face rig" in the detailed editor) loads all 34 of MakeHuman's face units (brows, lids, cheeks, nose, mouth, jaw, tongue) as separate GPU morphs instead of one expression at a time.

- Expressions blend smoothly into each other (`character.expressionFade`, 0.35 s by default) instead of switching.
- `character.setFaceUnits({ "mouth-open": 0.4, ... })` adds unit weights on top of expression and blink every frame, for lip-sync, gaze or your own face animation; `character.faceUnits()` lists the units.
- Lower level: `Human.faceRig(shape)` builds the rig (in the worker with the shape when `extras.rig` is set), `ThreeActor.setFaceRig(rig)` loads it and `ThreeActor.setFaceUnits(weights)` sets its weights. `buildFaceRig` in `@actors/core` is the renderer-free builder.

The rig is sparse: only the 12,800 vertices some unit moves are stored, as half floats in one texture per character (about 7 MB of GPU memory). A frame only uploads the 34 weights; the vertex shader adds the weighted units before skinning, on WebGL and WebGPU. Beards and tusks follow it like the expression morphs. It is off by default: it costs that memory and about 0.1 s in the worker per shape change. Robots and skeletons don't use it.

`ActorRuntime.surfaceDelta` takes an optional set of stencil meshes to compute (default: all, as before).
